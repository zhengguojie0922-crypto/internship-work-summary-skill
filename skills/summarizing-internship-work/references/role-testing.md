# Testing Role Guide

## Typical Chain Evidence

Trace testing chain evidence from requirement or defect through test design, fixtures, automation layers, assertions, environment setup, quality gates, failure reports, and production fixes. Link each test to the behavior it verifies.

## Impact Dimensions

Assess risk coverage, defect detection, regression protection, diagnosability, determinism, execution efficiency, release confidence, and test maintainability. Treat deletions of flaky or redundant tests as potentially valuable when evidence explains why.

## Evidence Topics

Use behavior and test attribution, the risk behind coverage, pre-fix failure evidence, execution environments, and defect or stability metrics as evidence topics. Route material gaps through the main consolidated confirmation process; this guide does not add confirmation rounds or request Git identity for a named-feature route.

## Pitfalls

Do not claim zero defects, complete coverage, prevention, or release impact from test presence alone. Separate test author, production-code author, defect reporter, and reviewer.

## Career Framing

Frame career evidence around identifying risk, designing a reliable verification strategy, improving feedback, and clarifying collaboration boundaries. Include metrics only when confirmed.
