# README 中文化设计

## 目标

将仓库根目录 `README.md` 的人类可读内容完整改写为简体中文，使中文用户可以直接完成安装、升级、卸载、调用和验证状态判断。

## 范围

- 将标题、段落、列表、表格标题、说明文字和验证状态改为中文。
- 保留所有命令块的可执行内容，不翻译命令、路径、环境变量、文件名、Skill 名称、模型 ID、版本号和错误码。
- 保留 Codex `35/35`、DeepSeek 已接受 `15/15`、HTTP 402 阻塞、当前版本未测试 Claude Sonnet，以及旧版本 Sonnet 运行不计入当前验收等事实边界。
- 更新 `tests/test_packaging.py`，让发布契约检查中文标题和关键中文声明，同时继续检查安装命令、路径、安全约束和模型标识。

## 非目标

- 不修改 `SKILL.md`、脚本、Schema、示例或工作流行为。
- 不改变安装目录、命令参数、版本号或支持范围。
- 不增加中英双语重复内容，也不引入新的发布承诺。

## 实现方式

采用结构保持式改写：维持 README 当前章节顺序与命令块位置，仅替换人类可读文本。技术术语在首次出现时保留必要的英文标识，例如 Codex、Claude Code、DeepSeek、Skill、Git 和 JSON。

测试按 TDD 执行：先将包装契约改为要求中文章节和关键状态文字，确认旧 README 失败；再改写 README，运行聚焦包装测试和全量测试。

## 验收标准

1. README 的所有人类可读章节以简体中文呈现。
2. POSIX Shell 与 PowerShell 命令保持原有语义和结构。
3. 安装、升级、卸载、调用、安全、产物、退出码与兼容性信息完整保留。
4. 模型验证状态不夸大、不遗漏旧版本 Sonnet 运行的排除说明。
5. `python -m unittest tests.test_packaging -v` 与全量测试通过。
6. 公开文本仍不包含本机绝对路径、私有网关地址或凭据。
